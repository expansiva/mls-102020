# agentDefsL2

Recreated on 2026-09-30 for page11 v2. The public artifact renders page intent, sections, organisms and molecule choices. Field paths and write bindings stay in `pipeline/agentDefsL2/page11Needs/<pageId><Device>.json`.

Run `@@agentDefsL2 <module>` for the full flow, or `@@agentDefsL2 <module> /pages` to stop at page11. Step JSON is `{ "project": N, "module": "<module>", "scope": "all" | "pages" }`. The full stages are `entry10 → input20 → pages50 → bff55 → shared60 → contracts70 → finalize80`. `/pages` is `entry10 → input20 → pages50 → finalize80`. Input20 reads the canonical L4/planner snapshot. pages50 generates one desktop/mobile page11 pair and two internal needs drafts per selected page. bff55 has the LLM design each page's endpoints and the page bindings (which key feeds each organism, what a command reloads, how a selection resolves, which organisms and endpoints serve each journey step) in `pipeline/agentDefsL2/bff/<pageId>.json`, with the origin of every leaf; leaves with a field origin take the ontology name and type. Code checks only facts (coverage, the input each write asks for, origins/rules visible to the page actors, bindings that exist, nothing outside the plan) and that the shared it derives passes its own gate; a failure goes back to the LLM once. shared60 derives the shared by code (d2_75): it transcribes the design and adds only facts (entry params by rule 8, the form from the write's input, descriptions from the JSDoc). contracts70 renders the contract with the JSDoc of each endpoint and meta from the origins; origins never reach it. All three run per page. finalize80 requires Studio compilation of page11 on both devices plus, in the full flow, the shared and the contract of each page in the run, and records ownership. A changed page draft redoes only that page's shared and contract. The same inputs reuse the receipt with no LLM call and no write. A file whose bytes no longer match the receipt `sourceHash` is drift and blocks finalize. An unavailable Studio compiler blocks; it never counts as approval. An older pipeline that still names finalize60 is a different format and is replaced, not migrated.

`/pages` compiles only the page11 pair and leaves shared and contract files untouched. The old `contracts30` remains frozen solely because L1 regeneration tests still import it; this flow does not execute it.

`steps/contracts30/` is frozen solely for the L1 regeneration test. Its remaining compatibility dependencies are `helpers/d2Core.ts`, `helpers/d2Intents.ts`, `helpers/d2Header.ts`, `steps/input20/{gate,io,contracts}.ts` and `steps/finalize60/{compile,io,contracts}.ts`. The input20 gate and IO only re-export shared snapshot code from `l2/helpers/defsInput/`.
