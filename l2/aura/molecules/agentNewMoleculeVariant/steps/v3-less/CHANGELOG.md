# CHANGELOG — v3-less

- 2026-07-23: created (Fase 2 do todo-agents-molecules-modelos-novos.md; spec: flow.json v3-less).
- 2026-07-24: prompt.md — added two rules after ml-discrete-slider-glass came out
  wrong (glass over-applied): (1) respect the origin .less property SCOPE per class
  (theme values, don't add new structural/surface props to a color-only class);
  (2) do NOT "glassify" small control primitives (thin tracks, stop marks/ticks,
  drag thumbs, floating indicators ≤ ~20px) — keep them color/border-color/opacity
  only, matching the origin; reserve blur/added-border/offset-or-spread box-shadow/
  specular ::before for real surfaces. Prompt-only nudge (no gate/code change).
- 2026-07-24: render-aware position-override GATE. After the slider `.ml-slider-thumb`
  set `position: relative` + `overflow: hidden` (overriding the render's `absolute`
  → full-width tooltip + clipped arrow), added a deterministic check: `position`/
  `overflow` are forbidden ONLY on classes the origin render positions absolute/fixed
  (`ctx.origin.absoluteMlClasses`, computed by v1-bootstrap via
  vOrigin.extractAbsoluteMlClasses). position/transform/display stay allowed on
  non-render-positioned elements (the brutal golden uses them). ::before/::after
  blocks are scrubbed first (they may position themselves). A blanket layout-property
  ban was rejected — it would break the golden (display/position/transform legit).
  Prompt gained a matching hard rule. Tests: v3-less gate + vOrigin extractor.

- 2026-07-24: prompt.md — added "Write ALL code comments in English, regardless of the user's language" (LLM was drifting to Portuguese comments in some files).

- 2026-07-28 (T13, todo-agent-new-theme.md Fase 10): new gate check `shadow_dom_selector`.
  The generated theme's base-typography recipe used `:host { ... }`, which matches nothing —
  these components render in LIGHT DOM (StateLitElement has no Shadow DOM), so the scope root
  is the tag itself. Verified first that `:host` appears nowhere in the 102040/102054/102055
  stylesheets nor in the two reference themes. `:host-context` and `::slotted()` are covered
  by the same check; prompt.md and skills/themeAuthoring gained the matching rule.
- 2026-07-28 (T10/T11/T12, todo-agent-new-theme.md Fase 10): GEOMETRY CONSERVATION.
  ml-number-range-slider-brutal came out with its rail at the top of the track and the
  handles centered below it: the sheet reproduced the origin's APPEARANCE but dropped the
  layout the origin `.less` had written (`position: absolute; top: 50%; height: 6px;
  transform: translateY(-50%)` on the rail, `width/height` on the handle, all of the
  tooltip's positioning). Strategy D scopes the base sheet to the BASE tag, so none of it
  reaches the variant — it must be reproduced. New gate check `geometry_dropped`, diffing
  `vOrigin.extractGeometryByClass` over the origin sheet (persisted by v1-bootstrap as
  `context.origin.geometryByClass`) against the same map computed over the generated sheet;
  only classes in the inventory are required. prompt.md gained the mirror rule ("do not ADD
  layout the origin lacks, do not DROP layout it has") and the thin-primitive border budget
  (a 3px border on a 6px rail leaves no fill). Also fixed a blind spot shared with the T3
  check: the selector regex did not re-enter a block nested directly inside another.
- 2026-07-27 (T3, todo-agent-new-theme.md Fase 10): new gate check `universal_selector`.
  The first theme generated by agentNewTheme prescribed `* { transition: none }` as its
  "motion stance"; in a molecule sheet that wipes animation the molecule INHERITS from its
  base (the SVG spinner the brutal theme deliberately keeps, only stepped) and leaks outside
  the tag scope. Detection inspects only the text PRECEDING a `{`, after scrubbing comments
  and attribute selectors, so `calc(100% * 0.5)` and `/* a * b */` do not trip it. Verified
  first that no validated sheet in 102054/102055 uses a universal selector; the real brutal
  golden still passes. The matching authoring rule lives in skills/themeAuthoring (rule 5).
- 2026-07-28 (T22, todo-agent-new-theme.md Fase 10): prompt.md — the OVERLAY decision is per
  molecule. If the molecule being derived IS an overlay (modal/dialog, dropdown panel, popover,
  tooltip), its container background takes the theme's overlay value even when the class carrying
  it is `.ml-surface-bg`, which means the INLINE surface in a card molecule. Evidence in the
  prompt: the modal card carries `ml-surface-bg` and `.ml-select-panel` reads
  `var(--ml-surface, ...)` in the base sheet — so a translucent theme that trusts the token pair
  alone reproduces the unreadable glass modal.
- 2026-07-29 (D3/Q6, todo-agents-molecules-modelos-novos.md Fase 3): the universal authoring
